## 調べ方
点検の道具：`analysis/checks/check_physics.py`

- 走行中の行（走り出し・目標深さの変化から 1.5 秒以降）を、距離 0.625 m（地形のマス2つ分）ごとに平均し、地形のマスによる約 0.6 秒の揺れを除いてから比べる
- 土の山の量の目安として、それまでに削った体積 `cut_volume` V（地山の体積）を使う
- FEE は McKyes の式（*Soil Cutting and Tillage*, 1985）。排土板の面と前方の地面のなす角 α = 180° − `blade_alpha_deg` ≒ 108°、ca = 0、上載荷重 q = 0。土と排土板の間の摩擦角 δ は未知なので、δ = 0、φ/3、φ/2、2φ/3 の範囲で予測を示す（式の形と記号の定義は原典で要確認）

| 項目 | 調べること |
| --- | --- |
| P1 | 前後の力と、削った体積（土の山の量）の関係 |
| P2・P3 | 土の山がないときの前後の力（削り始めの抵抗）と、深さとの関係を FEE と比べる |
| P4 | 上下の力と前後の力の比を FEE と比べる |
| P5 | 履帯の駆動力と、排土板を押す力・転がり抵抗のつり合い |
| P6 | 排土板を支える力（`lift_joint_effort`）と上下の力の連動 |


## 結果
### P1：前後の力は、削った土の量でほぼ決まり、約 20 kN で頭打ちになる
深さ 3・6・9・12 cm のすべての点が、削った体積 V に対してほぼ1本の曲線に乗る（`check_physics.png` の左の図）。

| 領域 | 結果（8 エピソードをまとめて近似） |
| --- | --- |
| V < 1.0 m³（63 区切り） | −F_x = 1.46 + 12.7 V [kN]（相関 0.85）、−F_z = 0.84 + 8.8 V [kN] |
| V > 2.0 m³（26 区切り） | −F_x 平均 20.1 kN（標準偏差 3.9）、−F_z 平均 11.4 kN |

- 直線の領域の傾き 12.7 kN/m³ は、**土の山を地面の上で引きずる力の目安 ρ g tanφ = 1474 × 9.81 × tan 40° = 12.1 kN/m³ の 1.05 倍**
- 力を決めているのは排土板の前の土の山の量で、深さそのものではない。深さは、土の山が育つ速さ（V = 排土板の幅 × 深さ × 走った距離）を決める
- 頭打ちの力 約 20 kN を ρ g tanφ で割ると V ≒ 1.65 m³（膨張率 1.28 をかけて、ほぐれた土で約 2.1 m³）で、図で頭打ちが始まる位置と合う。排土板が抱えられる土の量に限りがあり、それを超えた土は横からこぼれると考えられる。排土板の高さ（AGX の形状で約 0.96 m）と幅 2.96 m からの容量の目安（幅 × 高さ² × 0.8 程度、要確認）は約 2.2 m³ で、近い値

エピソードごとに直線で近似した値（参考）：

| 深さ | 傾き b [kN/m³] | 切片 a [kN] | 相関 |
| --- | --- | --- | --- |
| 3 cm | 13.5、15.2 | 0.14、0.38 | 0.93、0.97 |
| 6 cm | 9.9、10.4 | 1.76、2.12 | 0.80、0.97 |
| 9 cm | 5.0、5.0 | 7.36、8.60 | 0.64、0.88 |
| 12 cm | 1.6、4.1 | 10.25、14.94 | 0.44、0.79 |

深いエピソードほど記録の大部分が頭打ちの領域に入るため、直線で近似すると傾きが小さく、切片が大きく出る。**深いほど切片が大きいのは、削る抵抗が深さで増えたためではなく、近似の仕方によるもの**で、P2・P3 の比較には使えない。

### P2・P3：削り始めの抵抗は小さく、FEE より小さい
| 深さ | AGX（土の山がほぼないとき） | FEE δ = 0° | FEE δ = 13°（φ/3） | FEE δ = 20°（φ/2） |
| --- | --- | --- | --- | --- |
| 3 cm | 0.14〜0.38 kN（切片） | 1.98 kN | 5.15 kN | 11.51 kN |
| まとめて近似（V < 1.0 m³） | 1.46 kN（切片） | — | — | — |

- AGX では、刃先で土を切り崩す抵抗はごく小さく（FEE の δ = 0° の予測より小さい）、**反力のほとんどは土の山を引きずる力**
- FEE（q = 0）は刃先の前の土のくさびが壊れるときの抵抗を表す式で、AGX の反力の主な成分とは別のものを表している
- 深さとの関係（P3）は、上の理由でエピソードごとの切片からは判断できない。削り始めの抵抗が小さいため、AGX の反力から深さの依存性を取り出すのは難しい
- δ = 2φ/3 では、α + δ が式の成り立つ限界（約 135°）に近く、予測が発散する（または成立しない）

### P4：上下の力の向きは、δ ≒ φ/3 の FEE と合う
| 比（−F_z / −F_x） | AGX | FEE（V / H = −cot(α + δ)） |
| --- | --- | --- |
| 削り始めの分（切片の比、6 件） | 0.62 | δ = 0°：0.33、**δ = 13°：0.61**、δ = 20°：0.79 |
| 土の山の分（傾きの比） | 0.63（エピソードごと、0.34〜0.91）、0.69（まとめて近似） | 同上 |
| 平均の力の比 | 0.60（0.54〜0.72） | 同上 |

- 力の大きさは FEE と合わないが、向き（上下と前後の比）は、土と排土板の摩擦角 δ を φ/3 にした FEE とよく合う。上端が後ろに傾いた排土板（α > 90°）なので、土から受ける力は下向きになる
- 前後の力が 15 kN を超えるあたりから、上下の力の増え方が鈍り、約 11〜12 kN で頭打ちに近づく（`check_physics.png` の真ん中の図）

### P5：履帯の駆動力は、転がり抵抗 約 31 kN ＋ 1.46 × 排土板を押す力
| 項目 | 値 |
| --- | --- |
| 起動輪の半径（v_forward ÷ 履帯の回転速度） | 0.352 m（8 件とも 0.350〜0.354 m） |
| 駆動力 = 傾き × (−F_x) + 転がり抵抗 | 傾き 1.46（0.84〜1.88）、転がり抵抗 30.9 kN、相関 0.88（0.41〜0.93） |
| 排土板を上げて 0.5 m/s で走るときの駆動力（val_air_run × 3） | 32.2〜33.1 kN（P5 の転がり抵抗と一致） |
| 機体の質量（`d37pxi_24` の剛体の Mass の合計） | 約 11,000 kg（重さ 約 108 kN）。内訳：body_link 9,300 kg（手で入力された値）、blade_arm_link 1,440 kg、blade_link 115 kg（形状から自動計算）、ほか。履帯のノードの質量は含まれていない可能性がある |
| 転がり抵抗の係数 | 31 kN ÷ 108 kN ≒ **0.29** |

- 履帯の関節の力は N·m（回転の関節）。起動輪の半径で割って力に直した
- 転がり抵抗の係数 0.29 は、実際の履帯車両（土の上で 0.1 前後）の約3倍。OperaSim の履帯のモデルの内部の摩擦などが効いていると考えられる
- 傾きが 1 より大きい理由は未確定。履帯の動力の伝わり方の損失（効率 約 68% なら傾き 1/0.68 ≒ 1.47）や、排土板の下向きの力による荷重の増加が考えられる
- 左の履帯の力が右より 2〜5 kN 大きい（val_air_run で左 17.3〜18.9 kN、右 13.8〜15.8 kN）。関門3で見た、直進中に左へ向きが変わる現象（+0.1〜+1.1°）と合う
- 停止中（val_static）にも −4.5〜−4.7 kN の力が出る（速度指令 0 での関節の保持の力と考えられる）
- body_link の 9,300 kg は実機の運転質量に近い値が手で入力されており、そこに腕や排土板などの質量が別に加わるため、シミュレーションの機体は実機より重い可能性がある（実機の運転質量はカタログで要確認）

### P6：排土板を支える力は、上下の力とほぼ完全に連動する
- `lift_joint_effort` と `F_z` の相関：中央値 0.98（0.87〜1.00）
- 実機のリフトシリンダ圧に相当する信号から、上下の力をほぼそのまま読み取れる


## 分かったこと（まとめ）
1. **AGX の前後の反力は、「刃先で切り崩す小さな抵抗（約 1.5 kN）」＋「土の山の質量 × g × tanφ」でよく表せる。** 傾きは ρ g tanφ の 1.05 倍
2. **前後の力は、排土板が抱えられる土の量の限界で約 20 kN に頭打ちになる**（削った体積 約 1.5〜2 m³ 以上）
3. 刃先の前の土のくさびの抵抗（FEE、q = 0）は、AGX の反力の主な成分ではない。大きさは FEE の δ = 0° の予測より小さい
4. 上下と前後の力の比は、δ = φ/3 の FEE とよく合う（0.62 と 0.61）
5. 履帯の駆動力と排土板を支える力は、排土板の反力と連動している。ただし履帯の転がり抵抗が大きく（係数 0.29）、駆動力から排土板の力を推定するには、転がり抵抗と傾き（1.46）の補正が必要


## PINN の物理項と関門6への示唆
| 分かったこと | 示唆 |
| --- | --- |
| 反力の大部分は土の山を引きずる力で、傾きは ρ g tanφ にほぼ一致 | 物理項の中心は、FEE のくさびの式ではなく「土の山の質量 × g × tanφ」の形が適している。土の山の量は `cut_volume`（と膨張率）から計算できる |
| 力は排土板の容量で頭打ちになる | 物理項に容量の限界を入れるか、頭打ちの前の区間（削った体積 1 m³ 未満）だけを学習・物理項に使う |
| 傾きは ρ と tanφ の**積**で決まる | 前後の力の増え方だけでは、密度 ρ と摩擦角 φ を区別できないおそれがある。関門6で ρ と φ を別々に変えて確かめる |
| 削り始めの抵抗が小さい | 粘着力 c の影響が反力に表れにくいおそれがある（dirt_1 の c = 2100 Pa は小さい）。関門6で c を大きく変えて確かめる |
| 上下と前後の力の比は δ ≒ φ/3 の FEE と合う | 力の向き（比）が φ を区別する手がかりになる可能性がある。関門6で φ を変えたときに比が変わるかを確かめる |
| 排土板を支える力と上下の力の相関 0.98 | 実機の信号（リフトシリンダ圧）を入力に使う場合の根拠になる |


## 関門3のレポートの訂正
関門3の「そのほかの性質」の表の「履帯の駆動力の和と排土板の力：駆動力の和 約 17 kN」は、履帯の関節の力（N·m）をそのまま力として読んだ値だった。起動輪の半径 0.352 m で割ると、駆動力の和は約 48 kN（転がり抵抗 約 31 kN を含む）。
