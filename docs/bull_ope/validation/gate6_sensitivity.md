## 1. 目的
次の2つの問いに答える。この研究で土質を反力から推定できるかの根拠になる。

1. **再現性：** 同じ条件で繰り返すと、反力の特徴はどのくらいばらつくか
2. **識別可能性：** 土質（c、φ、ρ）を変えたとき、反力の特徴はそのばらつきより十分大きく変わるか

関門5の結果から、次の仮説を立てた。

| 仮説 | 根拠（関門5） |
| --- | --- |
| H1：ρ と φ は、前後の力だけでは区別できない | 前後の力の増え方が ρ g tanφ（ρ と tanφ の積）で決まる |
| H2：c の影響は小さい | 削り始めの抵抗が約 1.5 kN と小さい |
| H3：前後の力の傾きは ρ g tanφ で予測できる | 傾きが ρ g tanφ の 1.05 倍 |
| H4：速度の影響は小さい | 関門5はすべて 0.5 m/s で調べた |


## 2. 手段
深さ 9 cm・10 m を、土質と速度を**1つずつ**変えて削るエピソード `val_sens_*` を作った（`validation/data_check/sensitivity.py`）。深さ 9 cm なら削った体積が約 2.7 m³ まで増え、直線の領域と頭打ちの領域の両方を1回で記録できる。

| 条件（`val_sens_…`） | 変えたもの | 回数 |
| --- | --- | --- |
| `base` | 基準（dirt_1、0.5 m/s） | 5 |
| `c0`、`c10k`、`c30k` | c = 0、10、30 kPa | 各2 |
| `phi25`、`phi50` | φ = 25°、50° | 各5（2 + 追加 3） |
| `rho1200`、`rho1900` | ρ = 1,200、1,900 kg/m³ | 各2 |
| `rho1200_phi46`、`rho1900_phi33` | ρ × tanφ を基準と同じにした組み合わせ（φ = 45.85°、33.04°） | 各2 |
| `v03`、`v08` | 速度 0.3、0.8 m/s | 各2 |

`check_sensitivity.py` は、エピソードごとに特徴量を求め（関門5と同じく距離 0.625 m ごとに平均してから）、基準との差 z =（その条件の平均 − 基準の平均）÷ 基準の繰り返しの標準偏差 を出す。|z| ≥ 3 を「区別できる」の目安とした。

| 特徴量 | 内容 |
| --- | --- |
| `kx`、`ax` | 前後の力の傾き [kN/m³] と切片 [kN]（削った体積 1 m³ 未満で近似） |
| `kz`、`kz/kx` | 上下の力の傾きと、上下と前後の比 |
| `Fx_sat`、`Fz_sat` | 頭打ちの前後・上下の力 [kN]（削った体積 2 m³ 以上の平均） |
| `Fpen` | 貫入抵抗の平均 [kN] |

## 4. 考察
### 4.1 使える特徴量
`Fz_sat`・`Fpen`・`Fx_sat` は変動係数 4〜9% で安定している。前後の力の傾き `kx` と切片 `ax` は、深さ 9 cm では直線の領域が最初の約 3.7 m しかなく、区切りが数個しか残らないため大きくぶれる（関門5で傾きがきれいに求まったのは、8 エピソードをまとめて近似したから）。**1エピソードごとの傾き・切片は使わず、頭打ちの値と貫入抵抗で判断する。**

### 4.2 土質ごとの答え
| 土質 | 主に効く特徴量 | 関係 | 1エピソードでの分解能（目安） |
| --- | --- | --- | --- |
| c | `Fpen` | **`Fpen` ≒ 0.93 + 0.65 × c [kPa]**（4点ともこの直線に乗る） | 約 0.15 kPa（非常に細かい） |
| ρ | `Fz_sat` | ρ にほぼ比例（約 7.1 N/(kg/m³)）。頭打ちのときに排土板の上に乗る土の重さ | 約 65 kg/m³（約 4%） |
| φ | `Fx_sat` | φ とともに増えるが、増え方が鈍い（25° → 40° で +2.8 kN、40° → 50° で +1.8 kN） | 約 9°（粗い） |

分解能は、基準の近くでの特徴量の変化の傾きと、基準の繰り返しの標準偏差から求めた（ほかの土質と速度が分かっている場合）。

### 4.3 仮説の答え
| 仮説 | 答え |
| --- | --- |
| H1：ρ と φ は前後の力だけでは区別できない | 前後の力（頭打ち）については正しい（ρ × tanφ をそろえるとほぼ同じ）。ただし上下の力が ρ に敏感なので、組み合わせれば区別できる見込みがある |
| H2：c の影響は小さい | **外れ**。貫入抵抗が c にほぼ比例し、最も区別しやすい。関門5の dirt_1 の c（2.1 kPa）が小さかったため影響が見えにくかった |
| H3：傾きは ρ g tanφ で予測できる | 1エピソードごとの傾きが不安定で、この実験では確かめられなかった |
| H4：速度の影響は小さい | **外れ**。頭打ちの前後の力は速度にほぼ比例する（0.3 → 0.8 m/s で約 2 倍）。φ の影響（25° → 50° で約 1.3 倍）より大きい |

### 4.4 研究の設計への示唆
| 項目 | 示唆 |
| --- | --- |
| 推定器の入力 | `F_x` だけでなく、`F_pen`（c の手がかり）、`F_z`（ρ の手がかり）、速度を含める。`F_pen` は反力の内訳なので、実機で測れない場合の扱いを別に考える |
| 推定の対象 | c と ρ は推定しやすい。φ は分解能が粗いので、目標の精度を緩めるか、ρ × tanφ の形で推定することも検討する |
| 収集の設計 | 速度を変える（0.3〜0.8 m/s）。頭打ちの特徴を使うなら、削った体積が 2 m³ を超える深さ・距離にする（深さ 6 cm なら約 11 m 以上） |
| PINN の物理項の候補 | 貫入抵抗 ∝ c、頭打ちの上下の力 ∝ ρ、前後の力 ∝ ρ g tanφ × 土の山の量（関門5）で速度とともに増える |

### 4.5 注意点
- 1つずつ変えた実験で、組み合わせたときの影響は調べていない（ρ × tanφ をそろえた2条件を除く）。組み合わせは関門7で確かめた。
- 多くの条件は各2回で、z は基準の標準偏差で計算した。
- 膨張率とヤング率は変えていない。深さ・距離は固定。

| 主な特徴量の再現性が分かる | 満たす（`Fz_sat` 4.0%、`Fpen` 4.4%、`Fx_sat` 8.7%。傾きと切片は使えないことも分かった） |
| c・φ・ρ のそれぞれについて区別できるかを示せる | 満たす |
