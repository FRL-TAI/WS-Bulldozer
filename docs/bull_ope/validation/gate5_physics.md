## 1. 目的
AGX の反力が、土の力学の式（FEE：基本土工方程式）や力のつり合いと、**どの程度合うか・合わないか**を把握する。AGX の反力は FEE の式から直接計算されているわけではないので、完全な一致は期待しない。傾向（何が増えると力が増えるか）と大きさ（何倍くらいずれるか）を数値で示し、PINN の物理項に何を使えるかを決める根拠にする。


## 2. 手段
### 2.1 調べること（`check_physics.py`）
走行中の行（走り出し・目標の変化から 1.5 秒以降）を、距離 0.625 m（地形のマス2つ分）ごとに平均し、地形のマスによる揺れを除いてから比べる。土の山の量の目安には、それまでに削った体積 `cut_volume` V（地山の体積）を使う。

| 項目 | 調べること | 比べる相手 |
| --- | --- | --- |
| P1 | 前後の力を F_x = a + b V で近似したときの傾き b | 土の山を地面の上で引きずる力の目安 ρ g tanφ（dirt_1 で 12.1 kN/m³） |
| P2・P3 | 土の山がないときの前後の力（切片 a）と、深さとの関係 | FEE（McKyes の式、*Soil Cutting and Tillage*, 1985。式の形と記号の定義は原典で要確認）。排土板の面と前方の地面のなす角 α = 180° − `blade_alpha_deg` ≒ 108°、付着力 0、上載荷重 0。土と排土板の摩擦角 δ は未知なので 0、φ/3、φ/2、2φ/3 で予測 |
| P4 | 上下と前後の力の比 | FEE の予測 −cot(α + δ) |
| P5 | 履帯の駆動力（関節の力 ÷ 起動輪の半径）が、−F_x と転がり抵抗の和になっているか | 傾き 1、高い相関 |
| P6 | 排土板を支える力 `lift_joint_effort` と上下の力の相関 | 高い相関 |

## 3. 結果
### P1：前後の力と削った体積
深さ 3・6・9・12 cm のすべての点が、削った体積に対してほぼ1本の曲線に乗った。

| 領域 | 結果（8 エピソードをまとめて近似） |
| --- | --- |
| V < 1.0 m³（63 区切り） | −F_x = 1.46 + 12.7 V [kN]（相関 0.85）、−F_z = 0.84 + 8.8 V [kN] |
| V > 2.0 m³（26 区切り） | −F_x 平均 20.1 kN（標準偏差 3.9）、−F_z 平均 11.4 kN |

エピソードごとに直線で近似すると、深いほど傾きが小さく切片が大きく出た（3 cm：傾き 13.5〜15.2、切片 0.1〜0.4 kN／12 cm：傾き 1.6〜4.1、切片 10.3〜14.9 kN）。

### P2・P3：削り始めの力と FEE
| | AGX | FEE δ = 0° | δ = 13°（φ/3） | δ = 20°（φ/2） |
| --- | --- | --- | --- | --- |
| 深さ 3 cm、土の山なし | 0.14〜0.38 kN（切片） | 1.98 kN | 5.15 kN | 11.51 kN |

δ = 2φ/3 では α + δ が式の成り立つ限界（約 135°）に近く、予測が発散した。

### P4：上下と前後の力の比
| 比（−F_z / −F_x） | AGX | FEE |
| --- | --- | --- |

前後の力が 15 kN を超えるあたりから、上下の力の増え方が鈍り、約 11〜12 kN で頭打ちに近づいた。

## 4. 考察
- **前後の反力は「小さな切り崩しの抵抗（約 1.5 kN）＋ 土の山の質量 × g × tanφ」でよく表せる。** 直線の領域の傾き 12.7 kN/m³ は、土の山を地面の上で引きずる力の目安 ρ g tanφ = 12.1 kN/m³ の 1.05 倍。力を決めているのは排土板の前の土の山の量で、深さそのものではない。深さは、土の山が育つ速さ（V = 幅 × 深さ × 距離）を決めているだけ。
- **力は約 20 kN で頭打ちになる。** 20 kN を ρ g tanφ で割ると V ≒ 1.65 m³（膨張率をかけて、ほぐれた土で約 2.1 m³）で、頭打ちが始まる位置と合う。排土板が抱えられる土の量（容量の目安：幅 × 高さ² × 0.8 程度、排土板の高さ約 0.96 m で約 2.2 m³。式は要確認）を超えた土は横からこぼれると考えられる。深いエピソードほど切片が大きく出たのは、頭打ちの曲線に直線を当てはめたためで、削る抵抗が深さで増えたためではない。
- **FEE のくさびの抵抗は、AGX の反力の主な成分ではない。** 土の山がないときの力は FEE の δ = 0° の予測より小さい。ただし、**力の向き（上下と前後の比）は、δ = φ/3 の FEE とよく合う**。上端が後ろに傾いた排土板（α > 90°）なので、土から受ける力は下向きになる。
- **実機相当の信号は排土板の力と連動する。** 排土板を支える力と上下の力の相関は 0.98 で、実機のリフトシリンダ圧に相当する信号から上下の力をほぼそのまま読み取れる。履帯の駆動力も連動する（相関 0.88）が、転がり抵抗が約 31 kN（係数 31 kN ÷ 108 kN ≒ 0.29。実際の履帯車両は土の上で 0.1 前後）と大きく、傾きも 1.46 なので、駆動力から排土板の力を推定するには補正が要る。左の履帯の力が右より大きいことは、関門3の「直進中に毎回わずかに左へ向きが変わる」ことと合う。
- **シミュレーションの機体は実機より重い可能性がある。** `body_link` の 9,300 kg は実機の運転質量に近い値が手で入力されており、そこに腕や排土板の質量が別に加わる（実機の運転質量はカタログで要確認）。

**PINN の物理項と関門6への示唆**

| 分かったこと | 示唆 |
| --- | --- |
| 反力の大部分は土の山を引きずる力で、傾きは ρ g tanφ にほぼ一致 | 物理項の中心は「土の山の質量 × g × tanφ」の形が適している。土の山の量は `cut_volume`（と膨張率）から計算できる |
| 力は排土板の容量で頭打ちになる | 物理項に容量の限界を入れるか、頭打ちの前の区間だけを使う |
| 傾きは ρ と tanφ の積で決まる | 前後の力の増え方だけでは ρ と φ を区別できないおそれ（関門6で確かめる） |
| 削り始めの抵抗が小さい | 粘着力 c の影響が表れにくいおそれ（dirt_1 の c は小さい。関門6で確かめる） |


## 5. 判定
| 合格の条件 | 結果 |
| --- | --- |
| 傾向が物理的にもっともらしい | 満たす |
| 大きさのずれを数値で示せる | 満たす（土の山の傾き 1.05 倍、削り始めの抵抗は FEE の δ = 0° より小さい、力の比は δ = φ/3 と一致） |
| 力のつり合いが成り立つ | 満たす（駆動力の相関 0.88、排土板を支える力の相関 0.98） |
| 合わない点と理由の推定、物理項への示唆をまとめる | 満たす |

**合格**。
